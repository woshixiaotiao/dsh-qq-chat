## 4. 上传前可复现的检查命令

在本机仓库目录执行（输出为空即通过）：

```powershell
cd D:\AI\DSH\dsh-qq-chat

# 账号/凭据/私钥/用户名（尖括号占位请用你本机的真实值临时替换后执行，勿写入仓库）
git grep -nE "<MAIN_QQ>|<BOT_QQ>|<ONE_BOT_TOKEN>|<USER_NAME>|BEGIN [A-Z ]*PRIVATE KEY" -- .
# 完整 session UUID
git grep -nE "session-[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}" -- .
# 精确余额（用你本机的精确值替换占位）
git grep -nE "¥<精确余额1>|¥<精确余额2>" -- .
# 大文件（>10MB）
Get-ChildItem . -Recurse -File | Where-Object Length -gt 10MB
```

> 注：`git grep` 需要先 `git add`（索引中存在内容才可搜）；上传前跑一遍即可。
