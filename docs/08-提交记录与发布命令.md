## 2. 首次提交实际执行的命令（按顺序）

```powershell
# 1) 进入仓库
cd D:\AI\DSH\dsh-qq-chat

# 2) 初始化并设置提交身份（本仓库局部配置，不改全局）
git init -b main
git config user.name  "woshixiaotiao"
git config user.email "woshixiaotiao@users.noreply.github.com"

# 3) 上传前检查（详见 docs/07；输出为空才继续）
git grep -nE "session-[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}" -- .
Get-ChildItem . -Recurse -File | Where-Object Length -gt 10MB

# 4) 暂存 + 提交
git add -A
git commit -m "feat: DSH QQ Chat Bridge - NapCat/OneBot bridge, rotation, docs"

# 5) 关联远端并推送
git remote add origin https://github.com/woshixiaotiao/dsh-qq-chat.git
git push -u origin main
```

> 首次 `git push` 没有交互提示（本机 Git 凭据已缓存），退出码 0。

## 4. 日常更新（改完文件后）

```powershell
cd D:\AI\DSH\dsh-qq-chat
git add -A
git commit -m "update: <一句话说明>"
git push
```

或直接用脚本（自动先跑敏感/大文件检查，再提交推送）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\publish.ps1 -Message "update: <一句话说明>"
```

- `scripts/publish.ps1` 检查项：完整 session UUID、`C:\Users\<非占位用户名>`、私钥头、`sk-` key、>10 MB 文件；
- 检查命中 → 退出码 2/3 并**不提交**；无改动 → 退出码 0；
- 不会扫描 `.git/`，不会把配置/日志/数据库加进来（`.gitignore` 兜底）。

## 5. 如需改提交身份/邮件

```powershell
git config user.name  "新名字"
git config user.email "新邮箱"
git commit --amend --reset-author --no-edit
git push --force-with-lease
```
