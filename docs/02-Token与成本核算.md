# 02 · Token 与成本核算（QQ 对话 · 2026-10-22 00:25 实测）

> 数据来源：`~/.dsh/storages/session_projcache/sessions/<sessionId>.json` 的 `tokenUsage.totals`，用 `D:\AI\DSH\tools\cost-report.mjs` 同一口径计算。
> **是估算，不是官方账单**；用于阈值判断与横向比较。

## 1. 口径与公式

`cost-report.mjs` / `qq-bot-rotate.mjs` 统一口径（flash 非高峰估算）：

```text
估算成本(CNY) = (未命中输入 × $0.15 + 缓存读 × $0.003 + 输出 × $0.6) / 1,000,000 × 7.2
```

- 单位：token；单价按「美元/百万 token」；`7.2` 为汇率换算（历史口径，仅用于估算）。
- 「缓存读」= 命中上下文缓存的输入 token，占长会话成本大头。
- 桥空转/等待消息时**不产生模型调用**，成本为 0；只有 QQ 消息触发 DSH 会话回合才计费。

**解读**：

## 4. 省钱结论与建议

1. **聊天本身不贵**：按目前使用强度（每天几条到几十条），机器人月成本大概在 ¥1–5 级别；
2. **贵的是一段会话越来越长**：控制轮换阈值（`everyMessages` / `pressureTokens` / `costYuan`）；
3. **别在 QQ 里丢大文件**：prompt 里带长文会直接抬高未命中输入与缓存；
4. **桥空闲零成本**：不需要关机/停机省钱；只有消息触发回合才计费；
5. **余额闸**：`floorYuan: 30`，低于即拒绝调模型并回一句提示（本次实测会触发），充值后自动恢复；
6. 用 `node D:\AI\DSH\tools\cost-report.mjs` 随时复算；待机用 `node D:\AI\DSH\tools\standby-check.mjs` 确认没有定时器/唤醒。
